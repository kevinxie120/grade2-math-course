# 二年级数学课程首页设计规格

日期：2026-08-14

## 目标

将 GitHub Pages 根地址从“直接进入第一单元”改为独立课程目录。首页清晰展示第一至第五单元，儿童可以通过大尺寸课程卡片进入任意单元。

## 范围

本次只新增课程目录首页及其测试，不修改五个单元的课程逻辑、题目、存档格式或独立页面地址。

首页不读取 `localStorage`，不显示学习进度，也不限制单元访问顺序。五个单元始终可以直接进入。

## 页面架构

`index.html` 是独立、单文件、纯静态页面，内嵌全部 CSS，不依赖框架、字体服务、图片、接口或其他网络资源。首页通过相对链接访问同目录下的课程文件：

- `grade2-math-unit1.html`
- `grade2-math-unit2.html`
- `grade2-math-unit3.html`
- `grade2-math-unit4.html`
- `grade2-math-unit5.html`

第一单元继续保留独立地址；替换根目录 `index.html` 不会改变任何单元页面。

## 视觉与内容

首页采用彩色课程卡片网格，延续现有课程的圆角、大字号、柔和渐变和童趣视觉语言。

页面由以下部分组成：

1. 顶部课程介绍：课程名称、适用年级和一句简短说明。
2. 单元目录：五张结构一致的课程卡片。
3. 页面说明：提示学习进度只保存在当前浏览器，不会上传或跨设备同步。

每张课程卡片包含：

- 单元编号；
- 与主题对应的 Emoji 图标；
- 课程名称；
- 一句话知识点简介；
- “约 60 分钟”标签；
- 覆盖整张卡片主要操作的“开始学习”链接。

五个主题分别为：

| 单元 | 名称 | 图标 | 知识点 |
| --- | --- | --- | --- |
| 第一单元 | 数学星球大冒险 | 🪐 | 20以内加减、100以内数感与基础应用 |
| 第二单元 | 计算城建造师 | 🏗️ | 100以内加减法、进位、退位与验算 |
| 第三单元 | 小小店长 | 🛍️ | 人民币认识、付款、找零与预算 |
| 第四单元 | 乘法乐园建筑师 | 🧱 | 相同加数、乘法意义、阵列与生活模型 |
| 第五单元 | 口诀森林探险队 | 🌲 | 2至9乘法口诀与灵活计算策略 |

卡片使用不同主题色，但文字对比度和交互状态保持一致。页面背景使用轻量渐变和纯 CSS 装饰，不加入外部插图。

## 响应式与交互

- 宽屏采用三列网格，第二行自然容纳剩余卡片。
- 中等宽度采用两列。
- 手机采用单列，避免横向滚动。
- 主要链接的最小触控高度为 48 像素。
- 鼠标悬停时可轻微抬升；键盘焦点使用明显轮廓。
- 当系统启用 `prefers-reduced-motion: reduce` 时关闭非必要动画和过渡。

点击课程卡片或“开始学习”链接后，浏览器在当前标签页打开对应单元。浏览器返回按钮可以回到目录页。

## 无障碍

- 使用语义化的 `header`、`main`、`section`、标题层级和列表结构。
- 每个单元使用真实 `<a>` 链接，不用 JavaScript 模拟导航。
- 链接名称同时包含单元编号和课程名称，脱离视觉上下文仍能理解。
- 所有文字满足清晰可读的字号与颜色对比。
- 页面支持键盘完整操作，并提供跳至主要内容的链接。

## 数据与错误处理

首页不保存、读取或修改任何数据。五个课程链接是固定的相对路径。

构建测试必须确认所有目标文件存在，以防目录链接指向缺失课程。GitHub Pages 部署后的验收必须逐个请求五个地址并验证返回成功；若任何页面缺失，部署不视为完成。

## 测试策略

新增首页结构测试，验证：

- 五个单元链接恰好各出现一次且路径正确；
- 页面包含必要语义结构、跳转入口和数据说明；
- 不包含外部脚本、样式、图片或 HTTP 请求；
- 包含 48 像素触控目标、响应式断点和减少动画规则；
- 五个链接目标文件均存在。

新增浏览器验收测试，验证：

- 桌面、平板和手机宽度下卡片可见且无横向溢出；
- Tab 键可以依次聚焦五个课程链接；
- 每个链接都能打开正确课程并显示预期页面标题；
- 返回目录后其余链接仍可使用；
- 页面没有脚本错误和外部网络请求。

## 发布

实现完成后通过功能分支提交，创建 Pull Request，合并到 `main` 后由现有 GitHub Pages 配置自动部署。

部署完成必须验证：

- 根地址显示课程目录而不是第一单元；
- 五个公网课程链接均返回 HTTP 200；
- HTTPS 仍为强制开启；
- 线上 `index.html` 与合并提交中的文件内容一致。

## 验收标准

1. 访问 GitHub Pages 根地址能看到五个单元的课程目录。
2. 每张卡片能进入正确的独立单元页面。
3. 首页在桌面和 320 像素宽手机上均无横向溢出。
4. 键盘和屏幕阅读器可以理解并操作所有课程链接。
5. 首页完全静态、无外部依赖，不接触课程存档。
6. 自动化测试、Pull Request 合并、Pages 构建和公网验收全部通过。
